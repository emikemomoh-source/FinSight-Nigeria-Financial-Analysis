# FinSight-Nigeria-Financial-Analysis

# PROJECT DOCUMENTATION

## Project Type: FinSight Nigeria - Financial Performance and Cash Flow Analysis

My first Power BI financial analytics project, developed while learning at the Incubator Hub, investigating revenue growth, profitability and cash flow challenges in a Nigerian FMCG distribution company.

### Project Overview
Finsight Nigeria is a Power BI financial analytics project developed as part of my practical learning experience at the Incubator Hub. 
The project examines the financial performance of a Nigerian FMCG distribution company between 2024 and 2025, with particular attention to revenue growth, profitability, cost of sales, operating expenses and cash flow challenges.

 ### Data Source
 The financial dataset was provided by the Incubator Hub in Microsoft Excel format as part of the practical cas study exercise.

### Tools and Technologies Used
- Microsoft Exel: For recieving and initially examine the financial dataset.
- Power Query: Used for data cleaning and transformation.
- Microsoft Power BI: Used for data modelling, analysis and dashboard development. [Download Here](https://www.microsoft.com)
- DAX (Data Analysis Expression): Used to create measures and perform financial calculations.

### Data Cleaning and Preparation
The financial dataset was imported from Microsoft Excel into Power BI Desktop. 
Power Query was used to prepare the data for analysis.

The preparation process included:
- Examining the dataset and its structure.
- Checking and correcting data types.
- identifying and handling missing or inconsistent values where necessary.
- Ensuring financial amounts were in the appropriate numeric format.
- Preparing the tables for data modelling and analysis.
